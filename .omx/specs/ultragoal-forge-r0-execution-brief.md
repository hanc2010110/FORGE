# FORGE R0 execution brief

Build a trustworthy local-first engineering workflow that prevents hardware, firmware, tests, BOM, documentation, interfaces, costs, and evidence from silently drifting apart.

The implementation must make preflight validation durable before execution, retain append-only state and evidence, require revision-bound approvals, use quote-backed cost evaluation, and keep simulation clearly below physical verification. The application service is the sole owner of engineering state transitions and verdicts. R0 remains offline and loopback-only; actual device discovery, firmware flashing, motion, energization, or actuator control is explicitly prohibited.

Delivery is complete only after deterministic core tests, persistence and recovery tests, API security tests, the minimal operator workflow, documentation, cleanup, code review, and adversarial QA pass.
