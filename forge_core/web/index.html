02 · VERIFY

계획 대비 실제 변경 검증

preview hash와 실제 change analysis hash를 묶어 누락과 예상 밖 변경을 분리합니다.

VERIFY 대기 Plan verification과 evidence-plan verification은 release evidence로 사용되지 않습니다.

03 · RELEASE

불변 release decision 조회

project ID와 canonical decision hash를 입력하세요.

조회 값은 URL fragment에만 보존되며 서버 요청 로그나 외부 서비스로 전송하지 않습니다.

조회 대기 저장된 decision을 선택하면 변경·재시험·증거를 구성합니다.
